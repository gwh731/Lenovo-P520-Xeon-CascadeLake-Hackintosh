# Lenovo-P520-Xeon-CascadeLake-Hackintosh
How to Install macOS Tahoe 26.4.1 on a Lenovo ThinkStation P520-Xeon-CascadeLake-Hackintosh

# Overview
This Repository is intended to assist in the creation of a fully functional Lenvo ThinkStation P520 Hackintosh running Tahoe 26.4.1.

NOTE: This process is not for the faint of heart.  If you are the least bit squeamish about computer hardware or the finer points of the macOS, I implore you to turn away now. But if you have an eye for detail and enjoy the satisfaction of turning an unappreciated PC workhorse into a beautiful Mac treasure, then read on.

NOTE: The reason this is even economically feasable is because many companies are disposing of these noble workhorse computers.  Many times, you can pick them up for little or nothing as our society slips further down the slope of disposable consumerism. 

# Functionality
At the tinme of testing, system was fully functional running macOS Tahoe & Windows 11 25H2.

WHAT WORKS:
1. Native Bluetooth & WIFI
3. Audio (via VoodooHDA) --works great
4. Accelerated video (AMD Radeon Pro W6600)
5. Dual Boot: Windows 11 & macOS Tahoe 26.4.1
6. Mac boot chime!

WHAT DOESN'T WORK:
1. Front panel card reader
2. Firefox - Installs, but doesn't handshake correctly with accelerated graphics
